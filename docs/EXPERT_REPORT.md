# Описание решения Java Blueprints

Java Blueprints реализует путь Java-проект → граф → диагностика → преобразование → сравнение поведения. Сохранение поведения подтверждается на конкретном наборе входов, без заявления формальной эквивалентности для всех программ.

Клиент React/Monaco/React Flow отправляет весь Java-проект серверу Spring Boot. JavaParser строит AST и граф методов, конструкторов и инициализаторов. Анализатор находит дорогие вызовы, вложенные циклы, длинные методы, сложные ветвления и дубли. Оптимизатор использует консервативные шаблоны. Декомпозиция проверяет сборку и возвращает исходный проект при ошибке.

Клиент устанавливает результат автоисправления только после успешного Quality Gate: обе версии компилируются и запускаются с одинаковыми входами в отдельных JVM. Отчёт содержит результаты сценариев, ошибки сборки и измеренное отношение времени. Константного коэффициента ускорения нет.

В репозитории есть демонстрационный монолит заказов, стресс-пример на 939 строк с восемью входными наборами и независимый scope-пример с восемью наборами. Тесты проверяют обязательные конструкции языка/коллекций/исключений, UTF-8, а также record, enum, дженерики, лямбды и ограниченную оптимизацию Stream.filter.

## Ограничения

Разбор конструкции не означает наличие универсального автоисправления. Big-O оценивается эвристически, декомпозиция зависит от распознанных групп и допустимых границ извлечения. Ленивые/сложные Stream-цепочки и ссылочные сравнения автоматически не переписываются. Визуальные шаги графа не являются JVM-отладчиком. Подробный scope, отказы шаблонов и ограничения песочницы перечислены в README.

## Воспроизведение и доказательства

Веб-демо запускается через `docker compose up --build`; публичный URL отсутствует, ТЗ допускает воспроизводимую сборку. Проверки запускаются командами из README. Соответствие доработок пунктам сверки и фактические результаты — `SPEC_RECONCILIATION.md`. Процент соответствия всем требованиям не заявляется.
