# Исправления для `error-fix_Jomo`

Изменения выполнены по обязательному сценарию `case-01`: Java ↔ граф, редактирование AST, компиляция, запуск, Quality Gate с точным сравнением и воспроизводимый экспорт. Дополнительные языковые возможности из презентации не расширяют обязательный scope; файловая система, сеть, потоки и рефлексия пользовательского Java остаются за пределами разрешённого сценария.

## Что исправлено

- **Безопасность и работоспособность backend:** лимиты файлов, путей, тестов, stdin и вывода; нейтральные HTTP-ошибки; ограниченные очереди; атомарный отчёт; локальный CORS и bind портов на `127.0.0.1`.
- **Sandbox:** компиляция отдельным `javac` процессом; запуск в отдельной JVM с лимитами времени/памяти/вывода, очищенным окружением и Java policy; compose добавляет непривилегированный worker с внутренней сетью, `read_only`, `cap_drop`, `no-new-privileges`, `pids_limit` и tmpfs.
- **Quality Gate:** оригинал и кандидат всегда запускаются на одних тестах; stdout/stderr, код выхода, хвостовые пробелы и переносы сравниваются в `EXACT`; `expectedStdout` отдельно сверяется с оригиналом; переполненный вывод и неполный SSE отчёт не дают успех.
- **Оптимизатор и декомпозиция:** шаблоны применяются только при распознанной форме и сохраняют исходный fallback для null/нестандартных ключей/опасных побочных эффектов; результат декомпозиции отклоняется, если не компилируется; перенос методов, зависящих от полей, запрещён; квалифицированные ссылки вложенных типов переписываются.
- **Граф:** стабильные ID и переходы для ветвлений, циклов, `break`/`continue`, `return`/`throw`, switch fall-through, catch/finally; вставка метода идёт в класс, удаление блока проходит AST и компиляцию, добавление связи меняет структурный Java-контейнер.
- **Frontend:** все операции отправляют полный проект; вкладки и ручные правки синхронизированы; устаревшие async-ответы отбрасываются; Quality Gate применяет кандидат только при полном успехе; одинаковые имена тестов связываются по ID; свои тесты и тесты по умолчанию стартуют как `PENDING`; экспорт ZIP содержит все Java-файлы, тесты и инструкции; тема Monaco и fullscreen обрабатываются с ошибкой; SSE имеет таймаут и корректное завершение.
- **Диагностика и зависимости:** Big O учитывает конструкторы, убывающие циклы и реальные вложенные проходы; неподтверждённое ускорение не показывается как факт; Spring Boot обновлён до 3.5.16, Springdoc до 2.8.17, commons-lang3 до 3.18.0, DOMPurify зафиксирован на исправленной версии.

## Проверки

- Backend: Maven `clean test package` в JDK 21 контейнере, включая штатные тесты и регрессии sandbox, лимитов, графа, Big O и декомпозиции.
- Frontend: `tsc -b`, `vite build` и `node scripts/regressions.cjs` — 9 групп регрессий.
- Compose: `docker compose config` успешно разобрал сервисы `server`, `runner`, `client`, внутреннюю сеть и локальные bind-порты.

Живые клики в `http://localhost:3000/` не были автоматически подтверждены: системная browser policy запретила агенту доступ к сохранённому origin. Проверка исходников, store/API и сборки выполнена; это ограничение нельзя обходить.
