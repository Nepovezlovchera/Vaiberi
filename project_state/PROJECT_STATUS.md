# Состояние Java Blueprints

Актуальная реализация и запуск описаны в README. Доработки по сверке ТЗ отражены в docs/SPEC_RECONCILIATION.md. CI проверяет сервер и клиент.

Проект поддерживает многофайловые Java-программы, двусторонние правки графа, анализ, шаблонные оптимизации и Quality Gate. Успешная автоматическая проверка относится к выполненным тестам, а не ко всем возможным входам. Ускорение отображается по измерению; универсальные коэффициенты и процент полного соответствия не заявляются.

Публичного размещения демо нет; предусмотрена сборка Docker Compose. Наличие запущенных серверов зависит от окружения пользователя. Отправка ссылки организаторам не является частью изменений репозитория.
